# Presentacion Tipo Propuesta

## 1. Portada

QHere - Sistema de Control de Asistencia Escolar con QR

Desarrollador: Dustin Polanco

Administrador de proyecto: Jose Rijo

## 2. Problema

Los centros educativos necesitan registrar entrada, salida, tardanzas, ausencias y justificaciones de forma rapida, segura y auditable. Los procesos manuales consumen tiempo, generan errores y dificultan obtener reportes confiables.

## 3. Solucion

QHere centraliza la gestion de asistencia escolar mediante QR individual por estudiante, paneles por rol, control de horarios, justificaciones con evidencia y reportes administrativos exportables.

## 4. Objetivo General

Desarrollar una aplicacion web para administrar asistencia escolar por centro educativo, reduciendo errores operativos y facilitando el seguimiento de estudiantes, docentes y tutores.

## 5. Tecnologias

- Python + Flask para backend.
- React + Vite para frontend.
- Supabase para base de datos, autenticacion, storage y realtime.
- PostgreSQL como motor relacional.
- jsPDF y XLSX para exportaciones.

## 6. Modulos Principales

- Registro y aprobacion de directores.
- Gestion de centros educativos.
- Cursos, grados, secciones, turnos y horarios.
- Estudiantes con matricula unica y QR.
- Docentes con permisos y secciones asignadas.
- Padres/tutores y justificaciones.
- Escaneo QR, entrada, salida y contingencia manual.
- Reportes diarios, por estudiante y por docente.
- Auditoria, dispositivos autorizados y geolocalizacion opcional.

## 7. Seguridad

- Autenticacion con Supabase Auth.
- Control de acceso por roles.
- Aprobacion directiva por administrador absoluto.
- Separacion de datos por centro educativo.
- Bitacora de acciones sensibles.

## 8. Beneficios

- Menos tiempo registrando asistencia.
- Disminucion de duplicidad y fraude.
- Reportes listos para direccion.
- Mayor comunicacion con tutores.
- Evidencia digital para justificaciones.

## 9. Alcance

El sistema cubre los requerimientos RF-01 a RF-25 definidos para el proyecto, incluyendo funcionalidades obligatorias y algunas opcionales como geolocalizacion y dispositivos autorizados.

## 10. Cierre

QHere queda preparado como solucion academica completa para centros educativos que requieren control de asistencia moderno, seguro y documentado.
