# Cronograma de Actividades

## Fase 1. Analisis

- Levantamiento de requerimientos
- Identificacion de roles y flujos
- Definicion del modelo de datos

## Fase 2. Diseno

- Diseno de interfaz
- Diseno de arquitectura
- Diseno de base de datos y relaciones

## Fase 3. Desarrollo base

- Configuracion de Supabase
- Creacion del frontend React
- Creacion del backend Flask
- Modelado de escuelas, perfiles y estudiantes

## Fase 4. Desarrollo funcional

- Gestion de docentes y padres
- Generacion de QR
- Escaneo y asistencia
- Registro manual
- Excusas y evidencias
- Dashboard y reportes

## Fase 5. Calidad

- Correccion de errores
- Validacion de flujos por rol
- Compilacion de frontend
- Revision de scripts SQL

## Fase 6. Entrega

- Preparacion de README
- Manual tecnico
- Manual de usuario
- Acta y cronograma
- Evidencias y presentacion

## Formato sugerido para la entrega final

Puedes convertir este cronograma a tabla en Word o PowerPoint con columnas:

- Actividad
- Responsable
- Fecha inicio
- Fecha fin
- Estado
