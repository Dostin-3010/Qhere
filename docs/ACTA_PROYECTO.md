# Acta de Proyecto

## Nombre

QHERE - Sistema de Control de Asistencia Escolar con QR

## Patrocinador / direccion

Centro educativo solicitante

## Administrador de proyecto

Rijo

## Desarrollador

Jose Luis Polanco

## Problema

El control manual de asistencia genera errores, retrasos, poca trazabilidad y dificultad para producir reportes oportunos.

## Objetivo general

Desarrollar un sistema web de asistencia escolar con QR para mejorar el registro de entrada y salida, la gestion de incidencias y la supervision administrativa.

## Objetivos especificos

- Digitalizar la asistencia diaria por estudiante
- Reducir duplicidad y errores operativos
- Habilitar flujo de justificaciones con evidencia
- Generar reportes administrativos
- Mantener trazabilidad por usuario, dispositivo y horario

## Alcance

- Gestion de escuela, secciones, horarios y calendario
- Gestion de estudiantes, docentes y padres
- Asistencia por QR y manual
- Excusas, reportes y dashboard
- Integracion con Supabase Auth, DB y Storage

## Entregables

- Proyecto frontend y backend
- Scripts y respaldo de base de datos
- README
- Manual tecnico
- Manual de usuario
- Cronograma
- Evidencias visuales
- Presentacion del proyecto

## Riesgos

- Dependencia de configuracion correcta de Supabase
- Permisos de camara en dispositivos docentes
- Pendiente de proveedor para alertas por correo o mensajeria

## Criterio de aceptacion

El sistema debe permitir operar el flujo completo de configuracion, registro, asistencia, justificaciones y reportes en un entorno de demostracion funcional.
