# Capturas Requeridas de la Aplicacion

Las capturas deben guardarse en `04_CAPTURAS/PNG` dentro de la carpeta final de entrega.

## Capturas minimas

- Home / pagina principal.
- Login con seleccion de centro.
- Registro de director.
- Panel de administrador absoluto.
- Panel de direccion.
- Gestion del centro: cursos, grados, secciones, turnos y calendario.
- Gestion de estudiantes.
- Modal o vista de QR de estudiante.
- Gestion de docentes.
- Gestion de padres/tutores.
- Panel docente de escaneo.
- Bandeja de excusas.
- Reporte/exportacion PDF o Excel.
- Vista responsive movil si es posible.

## Recomendacion

Usar capturas con datos de demostracion reales para que se vea que el sistema esta conectado a Supabase y no es solo maqueta visual.
